# ColorOS 17 guide — corrections and feedback

This is the public feedback tracker for [coloros17.com](https://coloros17.com), an independent guide to ColorOS 17 release information, device eligibility and update guidance.

The website is not affiliated with or endorsed by OPPO. This repository contains feedback documentation only; it does not distribute firmware or the website source code.

## Report a correction

[Open a correction issue](https://github.com/linyangqing99/coloros17-feedback/issues/new?template=correction.yml) and include the affected page, the claim that needs attention and a reliable source. Device and region details are useful for rollout corrections.

Please do not include passwords, serial numbers, IMEI numbers, account details or other private information. For device repair, account recovery and official software support, contact OPPO through its official support channels.

Issues are public. A submission is not a guarantee of a reply or an official support response.
